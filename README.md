# 🌐 Estudos de Desenvolvimento Web

Repositório destinado a **armazenar, organizar e registrar minha jornada de aprendizado em Desenvolvimento Web**, reunindo conteúdos, exercícios e projetos desenvolvidos.

---

## 🛠️ Tecnologias

O foco principal deste repositório é:

* **HTML**
* **CSS**
* **JavaScript**

---

## 📚 Organização

Os conteúdos estão separados em diferentes pastas, de acordo com os cursos e disciplinas estudados.

Entre elas:

* **HTML**
* **CSS**
* **JavaScript**
* Outros conteúdos relacionados a Web

---

## 🎯 Objetivo

O principal objetivo deste repositório é **centralizar e registrar minha evolução no aprendizado de Desenvolvimento Web**.

> Este repositório está em constante evolução e novos conteúdos serão adicionados conforme avanço nos estudos.

---

## 💻 Projetos

O repositório pode conter exercícios, atividades, exemplos, testes e projetos desenvolvidos.

Cada projeto ou atividade possuirá sua própria pasta.

---

## 📌 Observação

Este repositório possui principalmente **finalidade educacional**.

Alguns códigos podem representar exercícios de cursos, testes, exemplos ou implementações realizadas durante o processo de aprendizado. Portanto, nem todos os projetos têm como objetivo representar uma aplicação pronta para produção.
